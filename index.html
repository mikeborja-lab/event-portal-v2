My role across the engagementSpreadsheet Automation Specialist → Full-Stack Google Workspace Developer

I designed the first working solution in Google Sheets, supported the client as the workflow matured, identified the limitations of direct spreadsheet interaction, proposed the Web App architecture, and then built the frontend and supporting Google Workspace integrations.

01Problem

The client needed one structured way to manage healthcare operational records, visits, billing activity, provider assignments, scheduling, and reporting. A spreadsheet was the practical starting point, but as the workflow grew, users were still working directly inside the same Google Sheet that also held the operational data.

02Approach

I first turned Google Sheets into a controlled working interface using structured entry fields, dropdowns, validation, conditional formatting, search and filtering controls, update actions, archive functions, and status-driven tracking. After observing the workflow in use, I proposed separating the user interface from the underlying data layer.

03Solution

Phase 1 delivered the Google Sheets operations system that centralized the workflow. Phase 2 evolved that foundation into a role-based Web App for records, visits, billing visibility, weekly matrix reporting, provider workload, calendar workflows, dashboards, and Google Workspace integrations—without requiring users to edit the database sheet directly.

04Result

The client moved through an incremental solution path rather than replacing the working process all at once: spreadsheet system first, dedicated Web App second. The same client relationship continued across two Upwork contracts totaling 320 billed hours, and both contracts received 5.0/5.0 ratings.
